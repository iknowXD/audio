# Проверка библиотеки и реакции на бас — 22 октября 2026

## Изменения

- Библиотека открывается логотипом audio. Метаданные и маленькие превью лежат в отдельном хранилище IndexedDB от оригинальных аудио/текстов/обложек: загрузка списка не читает все песни. Изменение записи и её файлов фиксируется одной транзакцией. При ошибке сохранения нет сообщения об успешной записи.
- Импорт пакета связывает аудио с текстами по имени; для единственной пары совпадение имени не обязательно. Для несовпавших имён интерфейс предлагает привязку через •••. При воспроизведении из библиотеки данные берутся из IndexedDB, пути/ссылки на временные исходные файлы не используются.
- Через ••• сохраняются название, артист, обложка и другой LRC/TTML. Ошибка файла выводится в форме. Правка только метаданных не перестраивает текст и обложку воспроизводимой песни.
- Переключение треков сериализовано, есть предыдущая/следующая, перемешанный порядок и повтор off/all/one. При естественном завершении repeat-one играет текущую песню, off останавливается в конце списка. Ручной Next переключает даже при repeat-one. Сохраняются выбранная песня и настройки очереди; при открытии автозапуска нет.
- Из основного экрана удалены старые кнопки и сдвиг текста, прямое редактирование обложки/метаданных. Отдельная страница редактора продолжает существовать по прежнему URL.
- FFT увеличен с 256 до 2048: прежние первые 11 частотных ячеек в основном находились выше диапазона баса. Для реакции теперь используется область 30–180 Гц, сглаживание анализатора 0.05, адаптивный уровень и быстрое обнаружение атаки. Толчок затухает за доли секунды. Видимое движение: сдвиг, масштаб и яркость пятен плюс световой ореол; текст не сдвигается от баса.

## Проверено

- 35 автоматических тестов проходят. Добавлены сценарии очереди, shuffle без повторов в одном проходе, previous, repeat off/all/one, привязка файлов, реакция баса при 44.1/48 kHz, отсутствие реакции на один среднечастотный пик, затухание в тишине. Production-сборка проходит.
- В браузере импортированы сразу две авторские тестовые песни, каждая со своим текстом; первая с обложкой. Обе появились с пометкой «Текст привязан». Проверены переключение и восстановление соответствующих текстов (три строки TTML / восемь строк LRC).
- Через форму первой песни сохранены название «Басовый пульс», артист «Аудиопроверка», обложка. После перезагрузки и отдельного перезапуска локального сервера они восстановились вместе с аудио/текстом. Вторая песня после перезапуска выбирается и играет без повторной загрузки файла.
- Проверены переключатели shuffle/repeat и ручное переключение. Естественный конец последнего трека при repeat-off оставил его остановленным: audio.ended=true, paused=true. При repeat-one зафиксирован возврат той же песни к началу.
- Синтетический WAV содержит удары 55 Гц с экспоненциальным затуханием и начальную тишину. Во время непрерывного воспроизведения CSS --pulse менялся, например, 0.039 → 1.000 → 0.568, далее затухал до 0.003 в тишине. Ореол и масштаб пятен следуют этой величине. Измерения: artifacts/bass-envelope-samples.json.
- При ширине 390 px ширина документа и меню 390 px, две песни видны, выбор закрывает меню. Проверен минимальный header: только библиотека и fullscreen, название не имеет роли кнопки. Мобильная проверка — эмуляция размера, не физический телефон.
- Консоль при проверке библиотеки без ошибок. Снимки: artifacts/library-preview.jpg и artifacts/library-mobile.jpg.

## Границы сохранения

Данные находятся в браузере на том же origin. Перезапуск сервера их не затрагивает. Очистка данных сайта, другой профиль браузера, другой адрес или устройство не предоставляют ту же библиотеку. Это локальная библиотека, без серверной синхронизации. Отдельная страница редактора имеет прежний способ хранения проекта и не подключена к аудиобиблиотеке автоматически.
