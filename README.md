# Audio

Музыкальная медиатека с синхронными текстами песен и редактором LRC / TTML.

## Что умеет

- Вход через Google, GitHub или почту и пароль.
- Личная библиотека, избранное и плейлисты.
- Общий каталог с поиском по песням, артистам и альбомам.
- Очередь, перемешивание, повтор и полноэкранный плеер.
- Пословная подсветка TTML, включая несколько одновременных строк.
- Обложки и баннеры из изображений, GIF и видео.
- Создание LRC из текста и разметка слов для TTML.

Музыку публикует администратор. Остальные пользователи добавляют песни из каталога в свои библиотеки. Редактор текстов и оформление артистов тоже доступны администратору.

## Запуск

Нужен Node.js 24.

```sh
npm ci
npm run dev
```

Адрес для разработки: `http://127.0.0.1:5173`. Локальные данные хранятся в `.local-data/`. В окне аккаунта доступны тестовые входы; на опубликованном сайте их нет.

```sh
npm test
npm run build
```

Клиент собирается в `dist/client`, сервер — в `dist/server`. Для проверки приложения с API используй `npm run dev`, а не `npm run preview`.

## Настройка входа

Сервер использует переменные `PUBLIC_ORIGIN`, `ADMIN_EMAIL`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GITHUB_CLIENT_ID` и `GITHUB_CLIENT_SECRET`. Секреты задаются в окружении сервера.

В настройках OAuth-приложений укажи адрес своего сайта и соответствующий callback:

```text
https://YOUR_DOMAIN/api/auth/google/callback
https://YOUR_DOMAIN/api/auth/github/callback
```

Чтобы подключить GitHub к существующему аккаунту, сначала войди привычным способом и выбери «Аккаунт → Подключить GitHub».

## Тексты песен

[Инструкция редактора](docs/lyrics-editor.md). Черновик можно сохранить в JSON, готовую разметку — в LRC или TTML.

## Устройство проекта

Клиент написан на JavaScript и CSS, сборка — Vite. Сервер работает как Worker, использует D1/SQLite и R2. Схема базы находится в `db/schema.ts`, миграции — в `drizzle/`. Новые миграции создаются командой `npm run db:generate`.

Аудио воспроизводится браузером; для неподдерживаемых кодеков используется [ffmpeg.wasm](https://github.com/ffmpegwasm/ffmpeg.wasm). Кодеки загружаются по необходимости и восстанавливаются из npm-пакета при сборке. DRM-файлы не поддерживаются.

FFmpeg Core распространяется по GPL-2.0-or-later. [Исходники и сборка](https://github.com/ffmpegwasm/ffmpeg.wasm-core). Лицензии остальных библиотек находятся в их пакетах.
