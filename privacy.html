Audio — музыкальный сайт с личной медиатекой, избранными песнями и плейлистами. Эта страница объясняет, какие данные нужны для его работы.

Вход и данные аккаунта

При входе через Google сайт получает идентификатор Google-аккаунта, имя и подтверждённый адрес электронной почты. Они используются для создания аккаунта Audio, входа и сохранения связанной с ним медиатеки. Разрешения Google ограничены базовыми данными профиля и почтой.

При регистрации по почте сохраняются адрес, указанное имя и защищённый хеш пароля. При входе через GitHub сайт получает стабильный идентификатор, имя и подтверждённую почту. Запрашивается только разрешение user:email, без доступа к репозиториям. Токен GitHub используется на сервере во время входа и не сохраняется в медиатеке или браузере. Google и GitHub — дополнительные способы входа: регистрация по почте также доступна.

Медиатека и файлы

В аккаунте хранятся выбранные песни, избранное, состав и оформление личных плейлистов, счётчики прослушиваний. Загружать музыку и публиковать её в общем каталоге может только администратор. Личные плейлисты и избранное доступны владельцу соответствующего аккаунта.

Аудиофайлы, тексты и оформление, загруженные администратором, сохраняются в серверном хранилище. Данные Google и GitHub используются для работы аккаунта Audio и его функций.

Хранение и защита

Сайт размещён на хостинге Sites и использует серверные хранилища Cloudflare для аккаунтов и файлов. Данные передаются по HTTPS. Служебная cookie поддерживает вход; настройки плеера и черновики редактора могут сохраняться в браузере. Для защиты входа ведутся служебные записи о попытках авторизации.

Данные аккаунта и медиатеки хранятся, пока аккаунт используется и до запроса на удаление. Чтобы запросить удаление аккаунта, медиатеки или данных входа Google или GitHub, напиши владельцу сайта с адреса, связанного с аккаунтом.
